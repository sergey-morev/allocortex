# Optional Modules


The core method should stay small. Add modules only when project scale, risk, volatility, or collaboration makes them useful.


- **Role capsule** — persistent role identity for repeated cold starts or multi-platform work.
- **Evidence / case index** — useful when evidence volume is large.
- **Source disposition register** — useful during migration, cleanup, deduplication, and archive work.
- **External proposal intake** — useful when outside reviewers/agents contribute material. Preserve the source as `PROPOSED` / advisory, adjudicate it separately, and promote only accepted consequences rather than the whole source memo.
- **HOT / WARM / COLD context tiers** — useful for large libraries with different activation frequencies.
- **Handoff template** — useful for multiple people/agents or discontinuous work.
- **Batch reconciliation** — useful when many chats/agents contribute candidate deltas.
- **Evidence genealogy** — useful when multiple apparent sources share one underlying episode or lineage.
- **Negative history** — preserves rejected paths so they do not repeatedly re-enter the project.
- **Rule-candidate lifecycle** — promotes repeated failure lessons into stable control rules.
- **Reverify windows/triggers** — useful for volatile external facts.
- **Sensitive-source pointers** — useful when evidence must remain outside the shared workspace.
- **Partitioned domain state** — useful when one project has several operational domains/lifecycles.
- **Draft / snapshot / acceptance lifecycle** — useful for reviewable deliverables.
- **Validation scripts** — justified only after schemas are stable and repeated human error is demonstrated.
