# Domain Profiles

Domain profiles add controls on top of the same semantic core. They are examples, not mandatory taxonomies.

## Software / high assurance
Possible additions: exact artifact identity, commit/SHA pointers, CI/test evidence, reproduction gates, release/deploy semantics, independent technical review.

## Research / editorial / publication
Possible additions: raw-source preservation, distillation, specialist review, draft/snapshot/acceptance states, case corpus, evidence-to-design feedback.

## Regulated / documentary work
Possible additions: official system-of-record pointers, fresh-source re-verification, filing/deadline gates, sensitive-source minimization, separation of operative work from long-horizon analysis.

## Field / practical operations
Possible additions: domain-current state, photo/invoice/work-order evidence, current-vs-historical equipment state, risk-first action ordering, explicit evidence required to resolve field uncertainty.
