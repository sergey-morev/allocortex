# Decision Log

Status: ACCEPTED DECISIONS ONLY

Use append-and-supersede semantics. Do not silently rewrite accepted history.

## D-001
DATE: [date]
DECISION: [accepted decision]
ACCEPTED_BY: [owner or explicitly delegated authority]
ACCEPTED_ON: [date/time, if known]
ACCEPTANCE_EVIDENCE_POINTER: [direct owner confirmation / approved PR / source reference to acceptance; UNKNOWN if not established]
BASIS / SOURCE POINTER: [reasoning or substantive evidence; distinct from acceptance evidence]
SUPERSEDES: [decision ID, if any]
STATUS: ACTIVE / PARTIALLY SUPERSEDED / SUPERSEDED

---

A plausible rationale or assistant classification is not evidence of owner acceptance. If acceptance is unverified, keep the item PROPOSED outside this log.

Only accepted decisions belong here. Proposals, reviews, recommendations, and model suggestions stay outside until accepted by the relevant authority.
