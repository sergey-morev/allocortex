# Router

Status: CURRENT NAVIGATION METADATA

The Router governs **activation and use**, not authority. The stable authority hierarchy belongs in `PROJECT_ANCHOR.md`.

For each source or source class:

## [Source / source class]
SEMANTIC_CLASS: [stable control / current state / accepted decisions / primary evidence / working analysis / archive / external system of record]
ACTIVATION: ALWAYS / TASK / CONDITION / MANUAL
USE_WHEN: [task condition]
LOCATION / ENTRYPOINT: [path, URL, external pointer rule, or `external; not packaged`]
STABLE_ID: [provider object ID / repository object / path+ID / equivalent, when supported]
DO_NOT_USE_AS: [forbidden authority or semantic role]

Prefer stable identifiers where the storage supports them. Names alone may be ambiguous, duplicated, or inconsistently indexed.

## Authority priority
See `PROJECT_ANCHOR.md`. This Router does not redefine it.

## Minimum retrieval rule
Read only the source classes needed for the current task. Do not bulk-load project history by default.

## Archive rule
Readable does not mean current. Superseded or historical material must retain visible non-current status.
